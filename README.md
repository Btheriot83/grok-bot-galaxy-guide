## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

Content lives in `content/` as typed TS modules (sourced from Stream Desk DIGEST / SOURCES / DAY3).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
